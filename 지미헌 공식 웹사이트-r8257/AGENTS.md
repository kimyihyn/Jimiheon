# 지미헌 知味軒 공식 웹사이트

## 이 앱
- 북촌 한옥의 한식 기반 프렌치 컨템포러리 파인다이닝 '지미헌'의 한 페이지 사이트. '레스토랑 주은' 풍의 넓은 여백, 1px 헤어라인, 카드 UI 없음, 투명도만 1.1초에 걸쳐 오르는 페이드인.
- 색: 한지 아이보리 #F8F6F1, 먹색 섹션 #181715, 푸터 딥 브라운 #2C221E, 글자 #1C1B19 / #5C5852, 포인트 브론즈 #9E8262. 서체: Cormorant Garamond(영문), Noto Serif KR(제목·인용), Pretendard light(정보).
- 섹션 순서: 상단 고정 메뉴(투명→아이보리 전환, KR/EN 토글) → 히어로(외부 사진 풀스크린) → Philosophy(음식디미방 철학, '디미방의 한 페이지' 박스, 3:4 메뉴판 액자) → Space(먹색, 내부 사진 6장 에디토리얼 그리드 + 라이트박스) → Cuisine(메뉴 사진 8칸, 호버 시 디미방 모티브, 코스·페어링 가격표) → Information & Reservation(캐치테이블 버튼, 홈페이지 예약 문의 모달) → 푸터.
- 이미지 주소는 전부 src/site/assets.ts 의 ASSETS 한 곳. 빈 값이면 라벨 달린 액자가 보인다(로고가 비면 처마 곡선 SVG 로고, 메뉴판이 비면 원목 책자 모양 액자). 캐치테이블 링크·전화번호도 같은 파일의 LINKS.
- 국문·영문 문구는 전부 src/site/copy.ts (ko/en 같은 모양). 메뉴 사진을 늘리면 copy.ts 의 dishes 도 같이 늘린다.
- 메뉴 이름 중 수증계 샤풍 프리카세만 사용자가 준 것. 나머지 7개 요리는 음식디미방 조리법(어만두·석류탕·섭산삼·대구껍질채·동아누르미·잡채·상화)을 모티브로 만든 예시라 실제 메뉴로 바꿔야 한다. 전화번호는 아직 없음.
- 사진은 지금 Unsplash 임시 이미지(한옥 외관 1장 외에는 일반 레스토랑 사진).

## 저장되는 것
- reservation 표: 홈페이지 예약 문의(방문일, 런치/디너, 인원 1–8, 와인 페어링 여부, 성함, 연락처, 기념일, 식이 제한, 응대 언어, 상태). 월요일·오늘 이전 날짜는 서버에서 거절.
- /admin(관리자 비밀번호 ADMIN_TOKEN): 예약 문의 목록, 상태 새 문의→연락함→예약 확정→방문 완료 / 취소. 설정 탭에서 '홈페이지 예약 문의' 받기/멈춤.
- 예약금 결제는 화면에 안내만 있고 실제 결제 기능은 없다.
